# luyaodot.github.io

My personal portfolio — a single-page site showcasing my work in UX research, UI design, and app development.

**Live:** [luyaodot.github.io](https://luyaodot.github.io)

## About

Built and maintained by **Luyao Zhao**. The site highlights selected projects, a brief about section, and ways to get in touch.

## Stack

- Plain HTML, CSS, and JavaScript — no build step
- Hosted on GitHub Pages
- Fonts: Syne, DM Mono, Lato (Google Fonts)

## Local preview

Open `index.html` directly in a browser, or serve the directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
